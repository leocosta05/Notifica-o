Como Publicar Gratuitamente

Para acessar de qualquer celular ou PC

Para o PWA e as Notificações funcionarem no seu celular, o site precisa ser publicado sob um endereço seguro (HTTPS). As formas mais simples e gratuitas são:

Opção 1: Vercel ou Netlify (Recomendado)

1. Salve este arquivo como index.html no seu computador.

2. Crie uma conta no site Vercel.com ou Netlify.com.

3. Arraste e solte o arquivo na plataforma para publicar instantaneamente com um link HTTPS.

Opção 2: GitHub Pages

1. Crie um repositório no GitHub.

2. Envie o arquivo index.html.

3. Nas configurações (Settings > Pages), ative o GitHub Pages. Seu site ficará online gratuitamente!

Como instalar na tela inicial

iOS (Safari): Toque no ícone de Compartilhar e selecione "Adicionar à Tela de Início".

Android (Chrome): Toque no menu de 3 pontos e escolha "Instalar aplicativo" ou "Adicionar à tela inicial".
